Glow stick törésanimáció – Klara gondolatmenete

Most végigvezetlek a gondolkodásomon, és megmutatom, hogyan tervezek meg egy teljesen új törésanimációt (5. feladat), majd hogyan láncolom össze időzítésekkel (6. feladat). A végén kapsz egy teljes HTML + CSS példát, amelyet be tudsz illeszteni Livresq-be.

🛠️ 5. Feladat – Saját törésanimáció tervezése

Gondolatmenetem

1. Más rázkódási minta

A korábbi rázkódás finom volt. Most valami karakteresebbet szeretnék: – gyors, rövid, „villámcsapás-szerű” mozgás – nem csak bal-jobb, hanem kicsit fel-le is – enyhe forgás, hogy drámaibb legyen.

Ezért a rázkódás így fog kinézni:

  • hirtelen balra csapódik
  • vissza középre
  • jobbra csapódik
  • vissza középre
  • egy kis fel-le vibrálás

Ez már sokkal „agresszívebb” törés-hatás.

2. Más repedésvonalak

A korábbi repedés két egyenes vonal volt. Most valami széttört üveg-szerű hatást akarok:

  • három repedésvonal
  • különböző szögek
  • egyik rövidebb, másik hosszabb
  • halványabb fény, hogy ne legyen túl harsány

Ez sokkal organikusabb törésérzetet ad.

3. Más fényerő

A felizzás legyen:

  • lassabb
  • mélyebb színű
  • kevésbé neon, inkább „kémiai reakció” jellegű
  • a fény ne azonnal robbanjon be, hanem „felkúszva” jelenjen meg

Ezért a fényerőt egy lassú, fokozatos gradient fogja felépíteni.

4. Hangulat: „villámcsapás” törés

A teljes animáció hangulata:

  • hirtelen rázkódás (villámcsapás)
  • repedésvonalak felvillannak
  • fény lassan terjed szét a rúd belsejében
  • végül stabilan világít

Ez egy drámai, energikus törés.

🔥 6. Feladat – Időzített töréslánc

Gondolatmenetem

A feladat szerint:

  • 0.5s rázkódás
  • automatikus felizzás
  • 3s múlva halványulás

Ehhez három animációt kell láncolni:

  • shake → 0.5s
  • ignite → 0.5s késleltetéssel indul
  • fadeout → 3s késleltetéssel indul

A CSS-ben ezt így oldom meg:

animation:
  shake 0.5s ease-out,
  ignite 0.8s ease-out 0.5s forwards,
  fadeout 2s ease-out 3s forwards;

Ez egy animációs „idővonal”.

🌈 A teljes HTML + CSS példa (új törésanimáció + időzítés)

Ez a végső megoldás, amit megterveztem:

<div class="stick" onclick="this.classList.add('break');"></div>

<style>
.stick {
  --glow: #00e0ff;
  width: 240px;
  height: 26px;
  margin: 40px auto;
  border-radius: 999px;
  background: #111;
  border: 2px solid #333;
  cursor: pointer;
  position: relative;
  transition: all 0.3s ease;
}

/* Törés animáció időzítése */
.stick.break {
  animation:
    shake 0.5s ease-out,
    ignite 0.8s ease-out 0.5s forwards,
    fadeout 2s ease-out 3s forwards;
}

/* 1. Rázkódás – villámcsapás stílus */
@keyframes shake {
  0%   { transform: translateX(0) translateY(0) rotate(0deg); }
  20%  { transform: translateX(-6px) translateY(-2px) rotate(-4deg); }
  40%  { transform: translateX(6px)  translateY(2px)  rotate(4deg); }
  60%  { transform: translateX(-4px) translateY(1px)  rotate(-2deg); }
  80%  { transform: translateX(4px)  translateY(-1px) rotate(2deg); }
  100% { transform: translateX(0) translateY(0) rotate(0deg); }
}

/* 2. Felizzás – lassú kémiai fényterjedés */
@keyframes ignite {
  0% {
    background: #111;
    border-color: #333;
    box-shadow: none;
  }
  100% {
    background: radial-gradient(circle at 50% 50%, var(--glow) 0%, #001018 70%);
    border-color: var(--glow);
    box-shadow:
      0 0 10px var(--glow),
      0 0 25px var(--glow),
      0 0 40px var(--glow);
  }
}

/* 3. Halványulás – lassú kihunyás */
@keyframes fadeout {
  0% {
    box-shadow:
      0 0 10px var(--glow),
      0 0 25px var(--glow),
      0 0 40px var(--glow);
    opacity: 1;
  }
  100% {
    box-shadow: none;
    opacity: 0.3;
  }
}

/* Repedésvonalak – három különböző szögben */
.stick.break::before,
.stick.break::after,
.stick.break .crack3 {
  content: "";
  position: absolute;
  left: 50%;
  top: 50%;
  width: 70%;
  height: 2px;
  background: rgba(255, 255, 255, 0.7);
  box-shadow: 0 0 8px rgba(255, 255, 255, 0.9);
  pointer-events: none;
}

.stick.break::before {
  transform: translate(-50%, -50%) rotate(12deg);
}

.stick.break::after {
  transform: translate(-50%, -50%) rotate(-10deg);
}

.stick.break .crack3 {
  transform: translate(-50%, -50%) rotate(3deg);
}
</style>
