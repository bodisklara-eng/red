Kapacitás: N = 20
Foglalt: 10 db
Lyukak (üres): 10 db
Kiválasztott slot: Nincs
🧺 Beszúrás (INSERT_AT)
🧼 Levétel (REMOVE_AT)
ESET 1: Foglalt helyre beszúrás O(k)
Jobbra tolás szükséges az első üres helyig (k = distance).
ESET 2/6: Belső lyuk kitöltése O(1)
A kiválasztott vagy balról legelső üres slot kitöltése tolás nélkül.
ESET 3: Beszúrás üres slotra O(1)
Nincs szükség elemek eltolására, közvetlen felakasztás.
ESET 4: Overflow (Meg telt) O(N)
Nincs több üres slot a kötélen, a beszúrás meghiúsul.
ESET 5: Levétel O(1)
Ruha levétele: null marad a helyén, lyuk keletkezik.
ESET 7: Kötegelt beszúrás O(m * k)
Anna egy egész adag ruhát mosott ki és akaszt fel egymás után.
ESET 8: Tömörítés balra O(N)
Minden ruha balra tolása, lyukak megszüntetése (defragmentálás).

📜 Algoritmus Napló

// JavaScript Implementáció
function findEmptyRight(rope, index) {
    for (let i = index; i < rope.length; i++) {
        if (rope[i] === null) return i;
    }
    return -1;
}

function insertAt(rope, index, newCloth) {
    if (rope[index] === null) {
        rope[index] = newCloth; // ESET 3: O(1)
        return;
    }
    let empty = findEmptyRight(rope, index);
    if (empty === -1) throw new Error("OVERFLOW"); // ESET 4
    
    // ESET 1: Jobbra tolás O(k)
    for (let k = empty; k > index; k--) {
        rope[k] = rope[k - 1];
    }
    rope[index] = newCloth;
}

function removeAt(rope, index, count = 1) {
    // ESET 5: O(1) lyuk keletkezik
    for (let i = 0; i < count && (index + i) < rope.length; i++) {
        rope[index + i] = null;
    }
}

function compress(rope) {
    // ESET 8: O(N) Defragmentálás
    let filled = rope.filter(item => item !== null);
    while (filled.length < rope.length) filled.push(null);
    return filled;
}
