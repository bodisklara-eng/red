Python Beszúró Algoritmus & Élő Memória

⚙️ Paraméterek Beállítása
🐍 Python Algoritmus
arr = [10, 20, 30, 40]
new_items = [25, 35]
idx = 1
for item in new_items:
arr.append(None)
for j in range(len(arr)-1, idx, -1):
arr[j] = arr[j-1]
arr[idx] = item
idx += 1
🧠 Memória / Változók
item: 35
idx: 3
j: -
Tömbműveletek: 10
9. Sor: idx növelése -> idx = 3
1. Összesen hány elem-mozgatási (értékmásolási) művelet hajtódik végre a beszúrások során?
