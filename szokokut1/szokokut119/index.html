Elem Törlése a Tömbből & Balra Tolás (Shift Left)

⚙️ Törlés Beállításai
🐍 Python Törlő Algoritmus
arr = [10, 20, 30, 40, 50]
del_idx = 1
removed_val = arr[del_idx]
for j in range(del_idx, len(arr)-1):
arr[j] = arr[j + 1] # balra léptetés
arr.pop() # utolsó felesleges elem törlése
🧠 Memória / Változók
del_idx: 1
removed_val: -
j: -
Másolások száma: 0
Rendszer alaphelyzetbe állítva.
1. Hány elemet kell balra tolni a tömb tömörítéséhez a megadott törlési index esetén?
💡 Minden elemet balra kell tolni, amely a törölt elem Mögött található.
🔍 A törlési index (1) mögött lévő 3 elemet kell balra tolni.
2. Mi történik az utolsó indexen lévő értékkel az `arr.pop()` sor lefutása előtt?
💡 Mivel az utolsó elemet is balra másoltuk, az utolsó helyen még ott marad a másolata (duplikálódik).
🔍 Az utolsó elem értéke (50) még a tömb végén marad a pop() előtt.
