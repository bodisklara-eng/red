Egyesével Történő Beszúrás Python Kódkövetéssel

⚙️ Beszúrás Beállításai
🐍 Python Beszúró Algoritmus
arr = [10, 20, 30, 40]
new_items = [25, 35]
idx = 1
for item in new_items:
arr.append(0) # hely nyitás
for j in range(len(arr)-1, idx, -1):
arr[j] = arr[j-1] # léptetés
arr[idx] = item # beszúrás
idx += 1 # következő hely
KÉSZ! Minden elem beszúrva. Végső tömb: [10, 25, 35, 20, 30, 40]
1. Milyen értékre módosul az idx változó az utolsó beszúrt elem után?
💡 Minden egyes beszúrás után az `idx` értéke 1-gyel nő (`idx += 1`).
🔍 A kezdő beszúrási index 1 volt, amihez a 2 beszúrás után 1-esével hozzáadódva az idx értéke 3 lesz.
2. Hányszor fut le a külső for item in new_items: ciklus?
💡 Pontosan annyiszor fut le, ahány elemet be szeretnél szúrni.
🔍 Mivel 2 elemet szúrunk be, a ciklus pontosan 2 alkalommal fut le.
