A buborékok repülési távolságai:
▶ Indítsd el az animációt!
A gép egymás után buborékokat fúj ki. A program minden távolságot összehasonlít az eddigi legnagyobb értékkel.
# A buborékok repülési távolságai tavolsag = [12, 25, 18, 42, 31, 27, 56, 39] max_ertek = tavolsag[0] for x in tavolsag: if x > max_ertek: max_ertek = x print(max_ertek) # 56
