Prelucrarea cifrelor unui număr natural

Extragerea ultimei cifre (n % 10) și eliminarea ei (n / 10) prin tăierea hârtiei

Informatică și TIC • Clasa a VI-a
Exemple:
💡 Apasă pe butonul „Taie ultima cifră!” (sau tasta Space) pentru a tăia ultima cifră din dreapta!
Ultima cifră din dreapta (de tăiat: n % 10) Numărul rămas pe foaie (n / 10)
Sfat: Poți tăia și apăsând tasta Space!

Algoritm în pseudocod

Structura repetitivă
citește n; suma ← 0; nr_cifre ← 0; oglindit ← 0
cât timp n > 0 execută
c ← n % 10              // extrage ultima cifră
suma ← suma + c; nr_cifre ← nr_cifre + 1
oglindit ← oglindit * 10 + c
n ← n / 10              // taie ultima cifră
sfârșit cât timp
scrie suma, nr_cifre, oglindit
